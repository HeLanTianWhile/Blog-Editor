# Blog‑Editor 博客编辑器
亮色简约轻量博客编辑器，纯前端实现，支持 Markdown、HTML、所见即所得三种编辑模式，支持文档导入导出与图片插入。

**[English](./README.md) | 简体中文**

## 项目介绍
Blog‑Editor 是零依赖单文件网页编辑器，全部逻辑在浏览器本地执行，不需要后端服务。

同一篇文档支持三种编辑模式自由切换：Markdown源码、HTML源码、所见即所得富文本。
左侧编辑，右侧实时预览；提供排版工具栏，在富文本模式选中文本会自动激活对应样式按钮。

## 功能特性
- 同一文档三种编辑模式：Markdown / HTML / 所见即所得
- 左右分栏布局：左侧编辑区，右侧实时预览
- 排版工具栏：加粗、斜体、删除线、标题、列表、引用块
- 样式检测：选中文本自动切换工具栏按钮状态
- 支持网络图片链接与本地图片上传
- 导入本地 Markdown、HTML 文件
- 导出 Markdown、HTML 文件
- 切换模式时自动同步文档内容
- 亮色简约界面
- 纯前端运行，无需部署、无需安装

## 使用方法
1. 使用现代浏览器直接打开 `index.html`
2. 在顶部控制栏切换编辑模式
3. 使用工具栏完成文本格式化与图片插入
4. 导入已有文档继续编辑，或导出文件保存内容

## 注意事项
- 内容保存在浏览器内存，请手动导出文件防止丢失
- 本地图片会转为 Base64 直接嵌入文档内
- Markdown 与 HTML 的互转面向普通博客写作场景
